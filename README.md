# Falling Pickaxe ⛏

Казуальная физическая игра: кирка падает в шахту, ломает блоки, отскакивает, улучшается на верстаках,
взрывает TNT. Между забегами — улучшения, кузница, предметы и престиж. Удержание: обучающий первый забег,
уровень игрока, ежедневные награды и задания, бесплатные сундуки, шахтёры (idle), коллекция, достижения,
«второй шанс», «лихорадка».

Полный геймдизайн, математика и дорожная карта: **[GAME_DESIGN.md](GAME_DESIGN.md)**.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 — открыть с телефона в той же сети или в мобильном режиме DevTools
npm test           # unit-тесты ядра
npm run sim        # симуляция баланса: npm run sim -- 600 42 --diff=hard
npm run playtest   # первые забеги нового игрока: темп, удары, баннеры, уровни
npm run build      # сборка в dist/
```

Управление: тап по левой/правой половине экрана (или ← →) — толчок; кнопка бомбы (или пробел) — динамит.

Первый запуск сразу открывает обучающий забег. Чтобы увидеть его снова — очистите сохранение:
`localStorage.clear(); location.reload()` в консоли браузера.

## Структура

| Папка | Что внутри |
|-------|------------|
| `src/game/` | Чистое ядро без DOM: блоки, биомы, генерация мира, физика, забег, экономика, сохранения, бот |
| `src/render/` | Canvas 2D-рендер, процедурные пиксельные текстуры, частицы |
| `src/audio/` | Синтез звуков WebAudio (без аудио-файлов) |
| `src/game/meta.ts` | Удержание: уровень, ежедневки, задания, достижения, сундуки, шахтёры, коллекция |
| `src/ui/` | `app.ts` — цикл и забег, `screens.ts` — экраны и модалки, `icons.ts` — SVG-иконки, i18n RU/EN |
| `src/game/profile.ts` | Аналитика по игроку: сессии, удержание, история забегов, сегмент, риск ухода |
| `src/analytics.ts` | Фасад аналитики: свойства игрока, журнал, пакетная отправка на сервер |
| `src/audio/music.ts` | Процедурная музыка (темы биомов, лихорадка) |
| `src/notifications.ts` | Локальные push-уведомления (планировщик, тихие часы) |
| `scripts/balance-sim.ts` | Симуляция прогрессии жадным ботом |
| `android/` | Нативный Android-проект (Capacitor) |

Весь баланс — в `src/game/config.ts` (+ HP/ценность блоков в `src/game/blocks.ts`).
После правок прогоняйте `npm run sim` и сверяйтесь с целями из раздела 5.6 дизайн-документа.

## Аналитика

* В игре: **Профиль** (тап по уровню на главной) — статистика игрока, график забегов, сегмент,
  удержание D1–D30, журнал событий и экспорт JSON.
* Отправка на свой сервер: соберите с переменной `VITE_ANALYTICS_URL=https://… npm run build` —
  события уходят пакетами (`POST {user, events}`) каждые 30 с и при сворачивании.
* Firebase / AppMetrica / GameAnalytics: вызовите `setAnalyticsSink((event, user) => …)` в `src/main.ts`.

## Уведомления

Работают в Android-приложении (`@capacitor/local-notifications`). В браузере не показываются.
Разрешение запрашивается после 2-го забега через мягкий вопрос в игре.

## Сборка под Android

Нужны Android Studio (JDK 21, Android SDK 35+).

```bash
npm run android:sync   # build + копирование в android/
npm run android:open   # открыть в Android Studio → Run на устройстве
```

Релиз в Google Play:
1. Поменять `appId` в `capacitor.config.json` (сейчас `com.fallingpickaxe.game`) на свой — после
   публикации изменить его нельзя.
2. Иконки и сплэш: `npx @capacitor/assets generate` (положить `assets/icon.png` 1024×1024).
3. Android Studio → *Build → Generate Signed App Bundle* → `.aab`; ключ подписи хранить вне репозитория.
4. Google Play Console: карточка, политика конфиденциальности, Data safety, рейтинг IARC,
   закрытый тест (≥ 12 тестировщиков × 14 дней для новых личных аккаунтов), затем продакшн.
5. Проверить актуальное требование Google Play к `targetSdkVersion` (`android/variables.gradle`).
